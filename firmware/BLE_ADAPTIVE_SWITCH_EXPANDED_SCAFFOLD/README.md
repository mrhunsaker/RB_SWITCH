# Archived Firmware

This directory contains an earlier adaptive-switch firmware implementation retained for historical reference.

It is **not the production RB Switch firmware** and is not part of the current three-button hardware documentation.

## Current production project

Use:

`firmware/RB_SWITCH_firmware/RB_SWITCH_firmware.ino`

The production RB Switch has three mechanical switch inputs:

| Switch | GPIO | Keyboard key |
|---|---:|---|
| SW1 | GPIO10 | Left Arrow |
| SW2 | GPIO11 | Enter |
| SW3 | GPIO12 | Right Arrow |

For current setup, operation, hardware, and firmware instructions, use the repository `README.md` and the `docs/` documentation.

No instructions in this archived directory should be used to configure or manufacture the current production RB Switch.
